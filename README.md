# centralina-nfc

Pagina aperta dal tag NFC della centralina di irrigazione. Il tag contiene un link
`https://montirob.github.io/centralina-nfc/#v=1&t=..&b=..`; i dati stanno dopo il `#`,
quindi il browser non li invia a GitHub. Dopo la prima apertura la pagina funziona offline.

Sorgente: `web/nfc/` nel repository del firmware (CentralinaWeedding). Pubblicata con
GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

Esempio: https://montirob.github.io/centralina-nfc/#v=1&t=1760414700&b=4213&p=5020&c=213&o=0&n=12&l=1760414400&d=15&s=180
